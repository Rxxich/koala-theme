# koala-theme

Конструктор тем для Koala Clash с живым превью. В центре сайта работает
макет клиента: можно переходить по страницам, подключаться, выбирать серверы, открывать меню и
диалоги. Все изменения сразу видны в окне. Готовая тема скачивается одним файлом `.css` и
импортируется в клиент.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:5178.

```bash
npm run build      # сборка в dist/ - статические файлы, можно положить на любой хостинг
npm run preview    # посмотреть собранную версию
npm run typecheck  # проверка типов
```

Пути в сборке относительные (`base: './'`), поэтому `dist/` работает из любой папки, в том числе на GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него эту папку (`koala-theme`) - она и есть корень репозитория.
   Если назвать репозиторий `<ваш-ник>.github.io`, сайт откроется по адресу `https://<ваш-ник>.github.io`,
   иначе - `https://<ваш-ник>.github.io/<репозиторий>/`.
2. В репозитории: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Каждый push в `main` собирает и публикует сайт (`.github/workflows/pages.yml`).

`node_modules/`, `dist/` и локальная папка `.claude/` в репозиторий не попадают (`.gitignore`).

## Что умеет

Стартовая тема - стандартный Koala Clash: палитра и оформление совпадают с клиентом, поэтому меняется
только то, что вы трогаете.

- **Палитра** - 20 ролей цвета для светлой и тёмной темы, плавающее окно палитры с образцами и проверкой
  контраста, 35 готовых палитр. Генератор гармоничных палитр в OKLCH: 7 схем (аналоговая, контраст,
  триада и др.), сочность, окраска фона, генерация от выбранного цвета.
- **Фон** - как в клиенте, цвет, градиенты с редактором точек, меш, 38 шаблонов, 22 фото с Unsplash
  и своя картинка по ссылке. Анимация, размытие фона на внутренних страницах, 16 узоров с масштабом,
  зерно, виньетка, настройка карты мира.
- **Поверхности** - как в клиенте или свои: прозрачность, стекло, рамки, скругление (0 - острые углы),
  стиль выбранного сервера и его наведения, профили (текущий, наведение, переключение), боковая панель
  и её активный пункт, кнопки. У каждой группы - свой цвет: акцент, цвет кнопки, цвет текста или любой.
- **Тени** - 16 стилей, направление, дальность, размытие, разброс, усиление при наведении, цвет.
- **Кнопка подключения** - 16 стилей: от стандартного до ракеты с пламенем, орбиты, радара, жидкости,
  эквалайзера, кардиограммы, портала и тумблера. Подсветка позади (сила, размер, мягкость, цвет, дыхание),
  форма, заливка, иконка, наведение, анимация в покое, скорость.
- **Анимации** - кривая и скорость, появление карточек, 7 эффектов нажатия (волна как в Koala Sage & Night,
  капля, вспышка, блик и др.) с настройкой цвета, длительности и мест, где они работают.
- **Шрифты** - системные и около 50 шрифтов Google Fonts (в том числе Mulish), подключение по ссылке,
  тень текста, «Фикс флагов в описании сервера».
- **Флаги** - в углу, водяной знак, значок, круг, скрыть; затемнение, размытие, «не размывать у выбранного».
- **Фишки** - подсветка серверов по пингу, фон откликается на подключение, бегущая рамка и «дыхание»
  выбранного сервера, звёздочка у закреплённого, частицы (снег, звёзды, светлячки, дождь, лепестки,
  пузыри, конфетти) под карточками или поверх интерфейса.
- **Галерея** - 7 готовых тем и 17 шаблонов конструктора.
- **Экспорт** - `.css` (настройки зашиты в конец файла), правило для заголовка `custom-css`, ссылка
  «Поделиться», файл настроек `.json`. Отмена/повтор (Ctrl+Z / Ctrl+Shift+Z), автосохранение.

## Установка темы

Тему подключает провайдер: в ответе подписки он отдаёт заголовок `custom-css` со ссылкой на файл.
При обновлении подписки клиент скачивает файл и включает тему, пока профиль активен. Название темы
в списке - имя файла из ссылки.

Пример через Правила ответов (SRR):

```json
{
  "key": "custom-css",
  "value": "https://example.com/custom.css"
}
```

## Как устроено

```
public/
  preview/          макет клиента для превью
    index.html      разметка из исходников клиента (data-slot, data-guide, классы Tailwind)
    app.js          поведение макета и API window.KT для конструктора
    app.css         Tailwind клиента, собранный из его исходников (см. tools/app-css)
    map-*.svg       карта мира из стандартной темы
    twemoji-flags.woff2  шрифт флагов (в клиенте - twemoji.ttf)
  themes/           готовые темы (CSS-файлы) для галереи
src/
  lib/generator.ts  настройки → CSS темы
  lib/power.ts      стили кнопки подключения
  lib/shadows.ts    тени и тень текста
  lib/backdrop.ts   узоры и частицы
  lib/effects.ts    эффекты нажатия и фишки
  lib/types.ts      схема настроек
  lib/color.ts      цвет: RGB/HSV/HSL/OKLCH, смешивание, контраст WCAG
  lib/palette.ts    роли палитры, автоподбор, случайная палитра
  data/             палитры, градиенты, обои, шаблоны, список готовых тем
  components/       интерфейс конструктора
  snippets/         крупные куски CSS (сфера из частиц)
tools/app-css/      исходник для пересборки app.css
```

**Почему тема работает в клиенте.** Koala Clash скачивает тему по ссылке из заголовка `custom-css` и вставляет её через `webContents.insertCSS()` *перед*
своими стилями, поэтому при равной специфичности побеждает клиент. Генератор начинает каждое правило
с `:root` (или `html.dark` / `html:not(.dark)` для палитр) - так правила темы сильнее. Макет повторяет
этот порядок: тема вставляется в `<style id="kt-theme">` до `app.css`.

**Ограничения клиента.** В `index.html` клиента стоит CSP `default-src 'self'; img-src * data:`.
Картинки по любой ссылке и `data:` работают, а внешние шрифты могут быть заблокированы - конструктор
предупреждает об этом и подсказывает установить шрифт в систему.

## Как добавить готовую тему в галерею

1. Положите файл в `public/themes/`.
2. Добавьте запись в `src/data/themes.ts`: название, файл, описание, 5 цветов для миниатюры
   (фон, карточка, акцент, начало и конец градиента кнопки) и id похожего шаблона конструктора.

## Как пересобрать CSS клиента

Готовый `public/preview/app.css` лежит в репозитории, и для сборки сайта исходники клиента не нужны.
Пересобирать его нужно, только если клиент обновился и разметка изменилась:

1. Положите исходники клиента рядом с папкой проекта, обновите путь `@source` в
   `tools/app-css/input.css` на их `src/renderer/src` и перенесите изменения из `assets/main.css`.
2. Выполните `npm run build:app-css`.
3. При необходимости поправьте разметку в `public/preview/index.html` и `app.js`.
